    ☁️ 雲端同步設定
    資料會同步到你自己的 GitHub 私有 repo（一個 state.json），各裝置自動合併，不必再手動搬檔。 Token 請使用 Fine-grained token，只授權該 repo 的 Contents：Read and write。
    首次使用請先在資料最新、最完整的那台裝置連線，其他裝置再連線，資料會自動合併。
    新裝置設定連結：在另一台裝置（例如手機）開啟此連結，就會自動帶入上面的設定。 連結含有 Token，請只傳給自己，用完就刪除。
    📂 匯入備份檔
    請先選擇備份放在哪裡，不會自動載入任何檔案。載入是與目前資料「合併」，不會清空現有任務。
    Chrome／Edge 不允許直接選「文件」「下載」「桌面」這幾個資料夾本身；備份放在那裡時，請用「直接選擇單一備份檔」。
